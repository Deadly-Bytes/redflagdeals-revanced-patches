Adds thumbs-down voting on individual replies and repairs the stale topic state returned to the thread list.

- Reply downvotes use the app's native permissions, selected state, and net score (upvotes minus downvotes).
- Thumb icons match the stock size and retain the native brief bounce animation after voting.
- Back navigation returns the refreshed topic model, allowing the list to receive updated server unread state.

Validated with 24 isolated JVM checks, strict stock-APK patch/decode/signature/alignment checks, altered-bytecode rejection, and Android 14 emulator checks in light/dark themes. A user-authorized downvote changed `+0` to `-1` and persisted after refresh.

Live undo/error rollback, the blue-dot transition on a naturally unread thread, and physical-device testing remain unverified.

Download `redflagdeals-revanced-patches-1.1.0.rvp` and apply **Fix RedFlagDeals Forums** to an unmodified RedFlagDeals Forums **1.11.7** APK using ReVanced Manager or CLI. Existing Manager source subscriptions discover the update after publication. This release distributes the patch bundle only.
